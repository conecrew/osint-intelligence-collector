# Visión del proyecto

OSINT Intelligence Collector es una plataforma modular para investigación técnica basada en fuentes abiertas. Su propósito es reunir observaciones de diferentes fuentes, conservar su procedencia y relacionarlas sin confundir asociación técnica con propiedad o autorización.

## Principios

1. Modularidad: cada fuente o técnica tiene un componente independiente.
2. Trazabilidad: cada dato conserva fuente y momento de obtención.
3. Correlación prudente: una coincidencia no demuestra titularidad.
4. Seguridad: escaneos activos limitados a activos autorizados.
5. Reproducibilidad: resultados exportables y documentados.
6. Desarrollo incremental: los módulos se implementan y prueban por etapas.

## Entorno de trabajo

Google Colab será un entorno útil para experimentar y conservar notebooks. El modo local Linux será necesario para operaciones que deban afectar el sistema del usuario, como una eventual modificación de /etc/hosts. Una sesión remota de Colab no modifica el equipo personal.
